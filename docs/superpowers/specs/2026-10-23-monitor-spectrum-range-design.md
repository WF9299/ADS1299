# Monitor 频谱范围选择

日期：2026-10-23。状态：用户已确认“按此实现，默认0–60 Hz”。

用户要求增加显示0–120Hz频谱的选项。当前频谱页固定显示0–60Hz，曲线截取和主峰搜索均使用60Hz上限。

## 推荐方案

在“频谱”页的通道选择旁增加“范围”下拉框，提供“0–60 Hz”和“0–120 Hz”，默认保持0–60Hz。选择后立即更新现有频谱图的标题、横轴、曲线截取和主峰搜索范围；无数据时同样更新横轴和标题，等待数据时不保留过期主峰。

复用原FFT计算、当前通道和显示滤波，不增加额外图窗；采样率限制FFT最高频率，横轴实际最高不超过奈奎斯特频率。正常1000SPS下两选项均完整显示。范围只在本次Monitor运行期间保存，与目前FFT通道选择一致。

可选替代是同时新增一幅固定0–120Hz图，但会占用侧栏高度并重复显示，不作为默认实施方案。

## 边界与验证

- 保留已有0–60Hz行为、HTTP特殊推送和本地原始记录；不用更新固件。
- 切换范围不改变带通设置。若观察90Hz以上成分，应自行选择原始或适当带宽的显示滤波。
- 用17Hz及100Hz合成信号检查：60Hz模式只显示低频范围，120Hz模式显示100Hz谱峰，主峰文字随范围更新；切回后立即裁回。
- 检查无数据状态、通道切换、显示滤波兼容和小窗口布局。此项为低影响显示修改，以现有相关回归及一次合成信号/静态GUI验证为主，不另建重复实现逻辑的测试套件。
