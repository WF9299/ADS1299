# Monitor HTTP 通道映射实施计划

依据已批准的2026-10-23设计，仅修改HTTP输出，不改ADS硬件采集。

1. 在工作区创建受原始哈希保护的统一C5源码副本；保留现有用户文件和本机配置。
2. HTTP设置升级到v2：默认原始8通道，增加模式和CH7/8来源，兼容v1，校验不同的1..6来源；纯函数在发送前复制数据并附带映射。
3. Monitor记录页增加模式/来源/说明，推送期间锁定，目的地预设独立，沿用启停清队列；记录页使用滚动容器适配增加的控件。
4. SSVEP接收端读取可选映射并放入原始记录和分析上下文；映射变更触发现有来源变化重置，算法保持原样。
5. 增加HTTP设置/映射/GUI/真实本机HTTP和SSVEP来源切换回归；完整PC测试及SSVEP测试只在最终实现后各运行一次，失败才追加定向验证。
6. 目视检查静态记录页，更新中文说明；核对外部文件哈希后应用到统一C5项目。保存两项目日志和重要记忆，报告验证范围和使用入口。

不占用串口、不烧录、不启动可见闪烁、不向电视地址发送合成或真实数据。本轮不自动推送新的功能提交。
