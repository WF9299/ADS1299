# HTTP特殊推送：CH1–CH6取源

- 用户明确选择仅修改HTTP输出，硬件仍采集8路；不修改ADS寄存器、BIAS参与掩码或正式原始记录。
- Monitor记录页新增原始8通道/特殊模式。特殊模式输出前6路不变，末两路从CH1–CH6选择不同来源，默认5/6；输出仍为200点×8列。目的地与映射独立，发送中锁定，停止后可改；本机设置v2兼容旧v1。
- 特殊包增加channel_mode和channel_map，映射在发送前复制构造，物理BIAS状态和时间戳/Marker不重写。配套SSVEP保留映射；来源改变会清窗并隔离旧标定模型，原始模式继续兼容旧包/旧标定来源。
- 8列只含6路独立测量，复制不代表新的电极或信号增强。第三方电视接收端需允许额外元信息；本轮仅验证本机接口，不向实际电视发送数据。
- 联合维护位置为本C5仓库。使用时重启Monitor与此仓库SSVEP，保持板端固件不变；设计和计划位于docs/superpowers对应2026-10-23文档。
