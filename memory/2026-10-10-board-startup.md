- UART monitor uses CP210x COM7, UART0 GPIO11 TX / GPIO12 RX at 115200. Firmware and bootloader logging are enabled. Board CP2102N RTS/DTR do not drive EN/BOOT: release BOOT (SW3), then press EN/RESET (SW2) after manual flashing.
- On first startup, C5 Flash and 8 MB PSRAM initialized successfully and app_main ran. ADS1299 ID repeatedly read 0x00 and CONFIG1 readback failed, so application returned before Wi-Fi/TCP startup.
- User confirmed JP1/JP2/JP3 were not installed. These must each connect their own source/load pins for normal ADS power: JP1 +2.5V_AVDD / TP5, JP2 +3.3V_DVDD / TP2, JP3 -2.5V_AVSS / TP7. Measure load-side rails against system GND, not isolated USB_HOST_GND. Power off before installing jumpers. Operation after installation remains to be verified.
- Existing ADS driver prints ID test passed when successful SPI calls return stable bytes, even for 0x00/0xFF; it first emits an invalid-ID warning and register readback later fails. Treat such a passed message as misleading, not proof of valid ADS communication. No firmware change was made during this diagnosis.

## Intermittent PWDN report

- Latest user reports ESP module physical pin 7 (GPIO1) and R25 ESP-side voltage stable at 3.3 V; R25 ADS-side voltage appears randomly as 3.3 V or 0 V. Continuity reported among R25 right/ADS-side pad, R54 upper pad and actual ADS PWDN pin. This supersedes the earlier assumption of a consistently high R25 output; downstream continuity does not establish an uninterrupted path through R25 and both solder joints.
- Application-wide search again finds GPIO1 configured as output/high once in ADS init and no later PWDN-low command or other application reuse. Intermittent R25/component solder connection is a leading hypothesis: the downstream 100 kOhm R54 pulls PWDN low when the upstream connection opens. Measurement/probe contact artifacts and intermittent downstream loading remain alternatives. This is not a confirmed hardware fault yet.
- Next discriminating checks: observe R54 upper versus lower voltage with probes fixed after normal boot, rather than repeatedly probing R25; power off all supplies/electrodes and measure the FULL path from ESP module pin 7 to R54 upper pad, expected approximately 33 Ohm plus probe/trace resistance. If resistance becomes high/OL with stable probes or gentle contact, prioritize R25/joint inspection and qualified rework. Do not substitute 0 Ohm or force PWDN to 3.3 V. New flash is not requested.
- TI ADS1299 Rev C section 9.4.3 confirms low PWDN powers down all on-chip circuitry; high is required to wake. https://www.ti.com/lit/ds/symlink/ads1299.pdf
